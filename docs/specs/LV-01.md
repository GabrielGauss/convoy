# Spec LV-01 — Rammer gate (speed-breakable rock wall)

- **Human owner/reviewer:** Gabriel (feel) + Narrative & Game Designer (placement) · **Builder agent:** combat-engineer · **Architecture:** ADR-001, ADR-006 § 2 (proposes D-023 `Convoy.Level`)
- **Split:** **LV-01a** new `Convoy.Level` module: config SO + pure rules + fracture layout + EditMode tests · **LV-01b** `RammerGate` runtime component + PlayMode test · **LV-01c** integration: config asset, generated `RammerGate.prefab`, test instance in `Sandbox` (executed by the orchestrator)

## Objective
A rock wall that blocks a shortcut and shatters only when a heavy-enough vehicle drives into it at ≥ 80 km/h closing speed (D-022, adapted from D-021's class-gated Rammer gates). Below the threshold it is a solid wall (D-01 impact damage applies as for any wall). Breaking costs a little speed; the debris is built from simple box chunks (no RayFire, no paid assets). Restart (scene reload) restores it.

## Scope
`Convoy.Level` asmdef + `Convoy.Level.Tests.EditMode`; `RammerGateConfig`, `RammerGateRules`, `ChunkSpec`, `WallFractureLayout`; `RammerGate`; prefab generator; Sandbox test instance.

## Out of scope
Placement in biomes (LV-03b), break VFX/audio/camera shake (later presentation task; `Broken` event provided), vehicle classes (Rammer/Scout, post-M1), damage to the breaker on a successful break (none by design: the reward), destruction by weapons (G-01), in-place reset without reload (D-029).

```csharp
// LV-01a — Assets/_Convoy/Scripts/Level/Convoy.Level.asmdef : references ["Convoy.Core"] only (ADR-001 shape of Combat)

// LV-01a — Assets/_Convoy/Scripts/Level/RammerGateConfig.cs
namespace Convoy.Level
{
    [CreateAssetMenu(fileName = "RammerGateConfig", menuName = "Convoy/Rammer Gate Config")]
    public sealed class RammerGateConfig : ScriptableObject
    {
        [Header("Break rule")]
        [Tooltip("Closing speed along the wall normal needed to break it, km/h. Glancing hits count only their normal component.")]
        [Min(1f)] public float breakSpeedKmh = 80f;
        [Tooltip("Lighter bodies (barrels, debris) never break it, kg. Jackal = 1200.")]
        [Min(0f)] public float minBreakerMassKg = 800f;
        [Tooltip("Breaker keeps this fraction of its horizontal speed after smashing through.")]
        [Range(0f, 1f)] public float speedRetention = 0.85f;
        [Tooltip("Depth of the trigger sensor in front of each face, m. Must exceed max speed × fixed step × 2 (52 m/s × 0.02 × 2 ≈ 2.1).")]
        [Min(0.5f)] public float sensorDepth = 2.5f;
        [Header("Debris")]
        [Min(1)] public int columns = 4;
        [Min(1)] public int rows = 3;
        [Range(0f, 0.3f)] public float jitter = 0.12f;          // fraction of chunk size, visual irregularity
        [Min(1f)] public float chunkMassKg = 40f;
        [Range(0f, 1.5f)] public float debrisSpeedFactor = 0.6f; // chunk velocity = breaker velocity × factor + spread
        [Min(0f)] public float debrisSpreadMps = 3f;
        [Min(0.5f)] public float debrisSettleSeconds = 6f;       // then chunks freeze (kinematic, colliders off)
    }
}

// LV-01a — Assets/_Convoy/Scripts/Level/RammerGateRules.cs  (pure maths on UnityEngine value types)
public static class RammerGateRules
{
    /// Speed toward the wall along its normal: n = wallForward × sign(dot(wallCentre − bodyPos, wallForward)); max(0, dot(v, n)).
    public static float ClosingSpeed(Vector3 velocity, Vector3 wallForward, Vector3 bodyToWallCentre);
    public static bool ShouldBreak(float closingSpeedMps, float massKg, RammerGateConfig config);  // NaN → false; inclusive ≥
    public static Vector3 RetainedVelocity(Vector3 velocity, float retention);                      // scales x,z; keeps y
    public static Vector3 DebrisVelocity(Vector3 breakerVelocity, float factor, float spread, int chunkIndex, int seed); // deterministic (System.Random(seed ^ index))
}

// LV-01a — Assets/_Convoy/Scripts/Level/WallFractureLayout.cs
public struct ChunkSpec { public Vector3 LocalCenter; public Vector3 Size; public Vector3 LocalEuler; }
public static class WallFractureLayout
{
    /// Splits a wall box (local, centred, size x = width, y = height, z = thickness) into columns × rows chunks with
    /// deterministic irregular seams (System.Random(seed)): column/row boundaries offset by ≤ jitter × cell size, then each
    /// chunk gets a ≤ 4° random rotation. Before rotation the chunks tile the wall exactly (no gaps/overlaps). Returns count.
    public static int Generate(Vector3 wallSize, int columns, int rows, float jitter, int seed, List<ChunkSpec> into);
}

// LV-01b — Assets/_Convoy/Scripts/Level/RammerGate.cs
[DisallowMultipleComponent]
public sealed class RammerGate : MonoBehaviour
{
    [SerializeField] private RammerGateConfig _config;
    [SerializeField] private BoxCollider _solid;      // non-trigger: the wall
    [SerializeField] private BoxCollider _sensor;     // trigger: solid expanded by sensorDepth on ±local Z
    [SerializeField] private Rigidbody[] _chunks = Array.Empty<Rigidbody>();  // children; kinematic, colliders disabled while intact
    [SerializeField] private int _seed;
    public bool IsBroken { get; }
    public event Action<RammerGate> Broken;           // presentation/telemetry only
    // Awake: validate refs (LogError), force sensor.isTrigger, chunks kinematic + their colliders disabled.
    // OnTriggerEnter/OnTriggerStay(Collider other): if !IsBroken && other.attachedRigidbody is non-kinematic:
    //     closing = ClosingSpeed(rb.linearVelocity, transform.forward, transform.position − rb.worldCenterOfMass)
    //     if ShouldBreak(closing, rb.mass, _config) → Break(rb).
    // Break(rb): _solid.enabled = false; rb.linearVelocity = RetainedVelocity(...) (the only write to a foreign body, ADR-006 § 2);
    //     rb.GetComponentsInChildren(_breakerColliders) (preallocated List) → Physics.IgnoreCollision with every chunk collider;
    //     chunks: collider on, isKinematic = false, mass = chunkMassKg, linearVelocity = DebrisVelocity(...); start settle timer; Broken?.Invoke(this).
    // FixedUpdate (only after a break): when settle time elapsed → chunks kinematic, colliders off; then enabled = false.
}
```

## Acceptance criteria
1. EditMode green. `ClosingSpeed`: head-on 25 m/s → 25; 45° → 17.68 ± 0.01; moving away → 0; from the back face → positive toward the wall. `ShouldBreak`: 22.22 m/s (80 km/h) & 1200 kg → true; 22.2 → false; 30 m/s & 40 kg → false; NaN → false.
2. `WallFractureLayout`: count = columns × rows; summed chunk volume = wall volume ± 0.1 %; all chunk AABBs (pre-rotation) inside the wall bounds; same seed → identical output; different seed → different seams; `jitter = 0` → regular grid.
3. PlayMode `RammerGateTests` (code-built ground, gate from code with 12 chunks, Jackal prefab via `AssetDatabase`, initial velocity set by the test): (a) 25 m/s head-on from 10 m → `IsBroken` within 1 s, the car's position passes 5 m beyond the wall within 2 s, horizontal speed right after the break = 0.85 × pre-break ± 5 %; (b) 15 m/s → not broken, car never passes the wall's back face; (c) 25 m/s at 60° to the normal (closing 12.5) → not broken; (d) after (a) and the settle time, every chunk is kinematic with colliders disabled.
4. Manual (Gabriel, after LV-01c) in `Sandbox`: hitting `RammerGate_Test` at ~60 km/h stops the car (D-01 damage ticks as for a wall); with a run-up + nitro at ≥ 80 km/h it shatters, the car keeps most of its speed and stays controllable (no flip in 5 of 5 tries); reloading the scene restores the wall; the orange marks read as "breakable".
5. Perf: `OnTriggerStay` and the settle `FixedUpdate` 0 B GC; while intact `FixedUpdate` returns on its first line; after settling the component disables itself.

## Perf constraints
No allocation in physics callbacks; `_breakerColliders` is a preallocated `List<Collider>(16)`, filled only at break time. ≤ 12 chunks per gate by default (≤ 30 hard cap in `OnValidate` warning).

## Risks
- High-speed car may tunnel through the 2.5 m sensor in one step only above ~125 m/s — far beyond the 52 m/s boost top speed.
- Debris launched forward can snag the breaker and flip it → permanent `IgnoreCollision` between chunks and the breaker; other vehicles (AI rivals) do collide with the 40 kg chunks (light pushes only) until they freeze.
- `speedRetention` write is a cross-module physics write → reviewed explicitly; in M2 must run where the breaker's physics is owned (ADR-005 note).
- Normal-component rule punishes angled approaches; ND may prefer total speed → a single rule change in `ClosingSpeed` usage (open question).
