# Spec RT-02 — Ghost of the best run

- **Human owner/reviewer:** Gabriel · **Builder agent:** vehicle-engineer · **Architecture:** ADR-001, ADR-006 §§ 1, 4 (proposes D-026)
- **Split:** **RT-02a** pure track/sampler/file format + EditMode tests · **RT-02b** `GhostRecorder` (Race) + `GhostRenderer` (Presentation) + PlayMode test · **RT-02c** integration: ghost material asset (executed by the orchestrator; no scene edits)

## Objective
Record the vehicle's pose during every run and, when the run is a new personal best, keep it as the sprint's ghost: saved locally, replayed on the next attempt as a translucent, non-colliding copy of the Jackal synchronised to the run clock. The player races their own best line — the strongest "one more try" driver after medals. Zero per-frame GC allocation, ≤ 512 KB RAM.

## Scope
`GhostFormat`, `GhostTrack`, `GhostSampler`, `GhostHeader`, `GhostFile`, `IGhostPlayback` (pure); `GhostRecorder`; `GhostRenderer`; ghost material asset.

## Out of scope
Ghosts of other players/rivals/medal-author runs (later: the author ghost could ship as a file — open question), wheel/steer animation, ghost audio, networking (ghosts are local only), multiple ghosts, ghost-vs-PB delta HUD (RT-01 splits cover it).

## Public interfaces
```csharp
// RT-02a — Assets/_Convoy/Scripts/Race/Ghost.cs
namespace Convoy.Race
{
    public static class GhostFormat
    {
        public const uint Magic = 0x54534743;         // "CGST" little-endian
        public const ushort Version = 1;
        public const int SampleRateHz = 25;           // every 2nd step at the 0.02 s fixed step
        public const float MaxSeconds = 300f;
        public const int MaxSamples = 7500;           // 300 s × 25 Hz → 7,500 × 32 B = 240 KB per track
        public const int BytesPerSample = 32;         // t, px, py, pz, rx, ry, rz, rw (floats)
        public const float TeleportDistance = 15f;    // consecutive samples farther apart = V-02 reset → snap, don't lerp
        public const float FinishTimeTolerance = 0.01f;
        public static string RelativePath(string sprintId);   // "ghosts/" + sprintId + ".cghost"
    }

    public interface IGhostPlayback
    {
        int Count { get; }
        float Duration { get; }                      // time of the last sample
        /// Interpolated pose at run time `time`. `cursor` is caller-owned (start at 0); amortised O(1) for increasing time,
        /// resets search if time goes backwards. Before the first sample → first pose; after the last → last pose.
        /// Returns false when Count == 0. Snaps (no lerp) across a teleport gap.
        bool Sample(float time, ref int cursor, out Vector3 position, out Quaternion rotation);
    }

    public sealed class GhostTrack : IGhostPlayback
    {
        public GhostTrack(int capacity = GhostFormat.MaxSamples);   // allocates three arrays once (SoA: float[], Vector3[], Quaternion[])
        public int Capacity { get; }
        public bool Overflowed { get; }               // a TryAdd failed for lack of space since the last Clear
        public void Clear();
        public bool TryAdd(float time, Vector3 position, Quaternion rotation); // false if full (sets Overflowed) or time <= last time
        public void GetSample(int index, out float time, out Vector3 position, out Quaternion rotation);
    }

    /// Fixed-rate sampling decision on the physics clock (accumulator, so a different fixed step still gives ~25 Hz).
    public sealed class GhostSampler
    {
        public GhostSampler(int rateHz);
        public void Reset();                          // next Step returns true (first sample at run start)
        public bool Step(float deltaTime);
    }

    public struct GhostHeader { public string SprintId; public string Vehicle; public float FinishTime; public ushort SampleRateHz; public int SampleCount; }

    public static class GhostFile
    {
        public static void Write(Stream stream, in GhostHeader header, GhostTrack track);   // BinaryWriter, little-endian, layout in ADR-006 § 4
        /// Reads into an existing track (Clear + TryAdd; no array allocation). false on bad magic/version, count > capacity, truncated stream.
        public static bool TryRead(Stream stream, GhostTrack into, out GhostHeader header);
        public static bool IsValidFor(in GhostHeader header, string sprintId, float personalBest);  // id match and |FinishTime − PB| ≤ tolerance
    }
}
```
**`Sample` rule:** advance `cursor` while `t[cursor+1] <= time`; `a = cursor, b = cursor+1`; if `(p[b]−p[a]).sqrMagnitude > TeleportDistance²` → return pose `a`; else `u = (time − t[a]) / (t[b] − t[a])`, `Vector3.LerpUnclamped`, `Quaternion.Slerp`.

```csharp
// RT-02b — Assets/_Convoy/Scripts/Race/GhostRecorder.cs
namespace Convoy.Race
{
    /// Self-bootstraps next to a SprintController that has a SprintDefinition (RuntimeInitializeOnLoadMethod + sceneLoaded hook,
    /// same pattern as SprintHud / RaceTelemetry). Runs after the vehicle simulated (ADR-006 § 8).
    [DefaultExecutionOrder(40)] [AddComponentMenu("")] [DisallowMultipleComponent]
    public sealed class GhostRecorder : MonoBehaviour
    {
        public IGhostPlayback BestGhost { get; }      // null when no valid ghost file
        public bool Recording { get; }
        // Awake: two GhostTrack(MaxSamples); TryOpenRead(RelativePath(id)) via SprintController.Save.Files → GhostFile.TryRead
        //        into _best; keep only if IsValidFor(header, id, SprintController.PersonalBest); log otherwise.
        // FixedUpdate: while Phase == Running: if _sampler.Step(dt) → _current.TryAdd(run.Elapsed, state.Position, state.Rotation).
        //              Sampler.Reset() on the Ready→Running transition.
        // On SprintController.Finished: add the final sample (run.Elapsed); if LastOutcome.IsNewBest && !_current.Overflowed:
        //              swap(_current, _best) — references only — and WriteBytesAtomic(RelativePath(id), s => GhostFile.Write(s, header, _best)).
    }
}

// RT-02b — Assets/_Convoy/Scripts/Presentation/GhostRenderer.cs
namespace Convoy.Presentation
{
    /// Self-bootstraps next to a GhostRecorder. Builds a visual-only copy of the player's vehicle once (MeshFilter.sharedMesh +
    /// GhostMaterial per MeshRenderer, poses relative to the vehicle root; NO colliders, shadows off) and moves only its own
    /// objects (D-007). Time = run.Elapsed + (Time.timeAsDouble − Time.fixedTimeAsDouble) clamped to [0, fixedDeltaTime] so
    /// motion is smooth between physics steps. Ready → shown at the first pose; Running → follows; after the ghost's last
    /// sample → holds 2 s then hides; Finished → hidden. G toggles visibility (Keyboard.current.gKey, like MusicPlayer's M).
    /// Alpha fades from 0.35 (≥ 12 m from the player) to 0.08 (≤ 3 m) through one reused MaterialPropertyBlock (_BaseColor).
    [AddComponentMenu("")] public sealed class GhostRenderer : MonoBehaviour { }
}
```

## Acceptance criteria
1. EditMode green. `GhostTrack`: capacity respected, `Overflowed` set, non-increasing time rejected; `Sample` interpolates mid-way exactly (±1e-4), clamps before/after, snaps across a 20 m gap, handles time going backwards; `Is.Not.AllocatingGCMemory()` for `TryAdd` and `Sample`.
2. `GhostSampler(25)` with dt 0.02 → true on steps 0, 2, 4, …; with dt 0.0166 → 25 ± 1 trues per simulated second.
3. `GhostFile`: write→read round-trip bit-exact; bad magic, version 2, truncated stream, count > capacity → false without exceptions; file length = header + 32 × count.
4. Memory: two tracks ≤ 512 KB (assert `Capacity × BytesPerSample × 2 ≤ 524,288`); nothing allocated by the recorder after `Awake` (Profiler: `GhostRecorder.FixedUpdate` 0 B).
5. PlayMode `GhostRecordTests` (`SaveRootOverride` temp dir, code-built straight 300 m, legacy finish gate at 200 m, Jackal full throttle): after finish, `ghosts/<id>.cghost` exists; sample count = 25 × elapsed ± 2; reloading the scene objects gives `BestGhost.Count` equal; `Sample(t)` at mid-run within 0.05 m of the recorded sample position. A slower second run leaves the file unchanged (timestamp + bytes).
6. Manual (Gabriel, after RT-02c) in `Sprint_01`: second attempt shows a cyan translucent Jackal following the first run's line; driving through it causes no collision; it fades when close; G hides/shows it; a reset in the PB run shows the ghost jumping, not sliding through rock; a new PB replaces the ghost on the next attempt; frame time unchanged (± 0.2 ms, Profiler).

## Perf constraints
Hot paths: `GhostRecorder.FixedUpdate`, `GhostTrack.TryAdd/Sample`, `GhostRenderer.Update` — 0 B GC, no LINQ, no `GetComponent` per frame. Renderer copies built once at spawn (`GetComponentsInChildren` into a preallocated `List<>` at spawn only). File IO only in `Awake` and at a new PB finish (~240 KB max, synchronous, < 5 ms).

## Risks
- Scene reload re-allocates the two tracks (~480 KB garbage per restart) — not per frame; acceptable; revisit with D-029 in-place reset.
- Retuning `VehicleConfig` makes old ghosts unbeatable/misleading → header stores `Vehicle`; PR-01c's "Backup and reset" clears them; no automatic invalidation in M1.
- Ghost overlapping the player's camera is distracting → distance fade + G toggle; C-01 camera unaffected (no colliders, not on a camera-collision layer).
- Transparent URP material sorting with the canyon fog may look off → visual check in AC 6; tweak material only.
