# Spec TK-00 — Track kit & spline spike

- **Human owner/reviewer:** Lead Dev (tech) + Gabriel (feel) · **Builder agent:** level-builder · **Architecture:** ADR-007 §1, §3, §5 (D-036, D-038)
- **Split:** **TK-00a** pure code: `RoadProfile`, `RoadMeshBuilder`, `JumpGate` maths, EditMode tests · **TK-00b** integration: `TK00_TrackKitSetup` editor script builds the test scene `TrackKit_Test` (orchestrator runs it) · **TK-00c** Gabriel drives it: feel + seam check + measured A/B speeds

## Objective
Prove that spline-extruded mesh roads work for CONVOY before building T01: stacked roads, welded seams, a speed-gated jump, an AI line from the same spline. The result decides D-036 (Accepted or amended). If generated roads are too costly, the fallback is ProBuilder-only roads for SEG1.

## Scope
- `com.unity.splines` added to `Packages/manifest.json` (D-036 is its package decision) and `Unity.Splines` to `Convoy.Level.asmdef`.
- `Convoy.Level`: `RoadProfile` (SO), `RoadMeshBuilder` (static, pure), `JumpGate` + `JumpGateConfig`, `TrackSegmentAuthoring` (thin MonoBehaviour).
- `Convoy.Editor`: `TK00_TrackKitSetup` (menu `Convoy/Integration/TK-00 Track Kit Test`, `ApplyToScene(string)`), idempotent and never deleting (ADR-001).
- Test scene `Assets/_Convoy/Scenes/Test/TrackKit_Test.unity` (orchestrator-owned).

## Out of scope
T01 layout (TK-01), class pieces other than one jump (CL-01), final materials (ART-01), terrain backdrop (TK-01), runtime mesh generation.

## Public interfaces
```csharp
namespace Convoy.Level
{
    public enum TrackEdgeKind { A, B, Shared, Sidecar, Heavy, Jackal }

    [CreateAssetMenu(fileName = "RoadProfile", menuName = "Convoy/Road Profile")]
    public sealed class RoadProfile : ScriptableObject
    {
        [Min(2f)] public float width = 12f;              // B ≈ 14, A ≈ 8, sidecar passage ≈ 2.4
        [Range(-5f, 5f)] public float camberDeg = 1f;    // subtle camber; less in fast sections
        [Min(0f)] public float shoulderWidth = 1f;
        [Min(0.1f)] public float sampleSpacing = 2f;     // m between cross-sections
        public bool guardRails = true;
        // No surface field: Level must not reference Vehicle (see note).
    }

    /// Pure: centre-line samples (position, up, tangent) → mesh arrays. Welds first/last cross-section to given end frames.
    public static class RoadMeshBuilder
    {
        public static void Build(IReadOnlyList<RoadSample> samples, RoadProfile profile,
                                 List<Vector3> vertices, List<Vector3> normals, List<Vector2> uvs, List<int> triangles);
    }
    public struct RoadSample { public Vector3 Position; public Vector3 Up; public Vector3 Tangent; public float Distance; }

    [CreateAssetMenu(fileName = "JumpGateConfig", menuName = "Convoy/Jump Gate Config")]
    public sealed class JumpGateConfig : ScriptableObject
    {
        [Min(0f)] public float clearMarginMps = 3f;   // JACKAL top speed + boost must beat MinClearSpeed by this
    }
    public static class JumpGateRules
    {
        /// True when a vehicle at <paramref name="speedMps"/> clears the gap (ChasmJump.MinClearSpeed + margin).
        public static bool Clears(float speedMps, float gap, float rampAngleDeg, float landingDrop, JumpGateConfig config);
    }
}
```
**Note (surface):** `SurfaceProfile` lives in `Convoy.Vehicle`, so `RoadProfile` cannot reference it (Level → Core only, ADR-001). The editor setup script (which may reference every module) adds the existing surface component that `WheelSurfaceCache` finds with `TryGetComponent` to each road collider, mapping edge kind → `SurfaceProfile` asset (A = rough, B = default). The mapping lives in the setup script's config, not in code constants.

## Test course (built by `TK00_TrackKitSetup`)
- One **300 m** B-profile road (14 m) on layer `Road_L1` with a 40 m **bridge** crossing over a 120 m A-profile road (8 m) on `Road_L0`. Clearance ≥ 6 m.
- One **speed-gated jump** on the upper road: gap and ramp chosen so `MinClearSpeed` ≈ JACKAL top speed + boost − 3 m/s (40 + 12 − 3 = 49 m/s). Without boost it fails and lands on the lower road.
- Roads built from 3 spline pieces joined end to end (tests seams on straight, curve and slope).
- One `RacingLine` per road sampled from its spline every 5 m.
- Physics layers `Road_L0`, `Road_L1`, `Road_L2` created if missing (orchestrator approves the TagManager diff).

## Acceptance criteria
1. **EditMode:** `RoadMeshBuilder` — correct vertex count for N samples; consecutive pieces share identical end vertices and normals (seam test); no degenerate triangles on a 90° curve with 5 m radius; 0 B GC after warm-up when reusing lists.
2. **EditMode:** `JumpGateRules.Clears` matches `ChasmJump.MinClearSpeed` + margin (table of 4 cases incl. +Infinity).
3. **EditMode:** two `PolylinePath`s stacked 8 m apart: `ProjectGlobal` from a point 1 m above the lower line returns the lower line's segment (ADR-007 §5).
4. **Integration:** running the setup twice changes nothing (idempotent); the scene builds from scratch in < 10 s.
5. **TK-00c, Gabriel (manual checklist):** JACKAL drives the full loop at top speed with no wheel snag at seams, under the bridge and over it; with boost clears the jump, without boost lands on the lower road; ≥ 60 fps in the test scene.
6. **Measured speeds:** the builder adds an EditMode-free telemetry note: average JACKAL speed on A-profile and B-profile (one lap each), reported in the PR. These replace the placeholder 30/38 m/s in `T01_topology.md`.
7. D-036 updated to Accepted (or amended with the reason) in `DECISIONS.md`.
