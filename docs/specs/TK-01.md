# Spec TK-01 — T01 Segment 1 (START → M4a), three layers, O-004 toggle

- **Human owner/reviewer:** Narrative & Game Designer (layout) + Gabriel (feel) · **Builder agents:** level-builder (setup script + data), gameplay-engineer (Race: fall toggle, layer-aware recovery) · **Architecture:** ADR-007 §1, §4, §5 (D-037, D-038)
- **Layout source:** `docs/tracks/T01/T01_topology.md` + `T01_topology.json` (SEG1), hand map `T01_map_overall.png`
- **Split:** **TK-01a** Race code: `RaceRulesConfig`, `LayerFallMode`, `LayerFallMonitor`, `TrackRecoveryPoints` + EditMode tests · **TK-01b** layout data: SEG1 splines (JSON → spline control points + heights) and setup script `TK01_Segment1Setup` · **TK-01c** orchestrator runs it, scene `T01_Seg1.unity`; Gabriel's playtest checklist (PT-A prep)

## Objective
Build the first ~3.4 km of T01 from Gabriel's hand map with real layers, so PT-A can answer two questions: is the layered track fun, and what should a layer fall do (O-004)? JACKAL only. Class connectors exist as **blocked stubs** (visible entrances closed by a barrier) so CL-01 can open them without moving roads.

## Scope (SEG1 = START → M4a)
| Piece (topology id) | Build |
|---|---|
| START → M0 | shared B-profile straight (~0.5 km), 4-wide grid start |
| M0 split → C2 | A (8 m, rough) and B (14 m, smooth) diverge |
| **C2 signature over/under** | B on `Road_L1` bridge over A on `Road_L0`, clearance ≥ 7 m; **no connection** (locked, D-037 amendment) |
| C2 → C3 | A climbs to `Road_L2` along its lobe (high ledge), B stays mid; A drops back to meet B |
| **C3 short merge** | ~100 m shared road; contact point; line change allowed |
| C3 → M4a | split again; meet at M4a (segment end + checkpoint/split marker) |
| Stubs | S3 (sidecar cut), H4 (heavy wall), H3 (heavy diagonal), S2 entry (sidecar tunnel), J24 launch ramp (JACKAL jump over the triple crossing onto its own track): each is a 10–20 m entrance stub with a blocking barrier |
| Triple-crossing stack (HANDMAP 4) | geometry reserved: three levels at map ≈ (330, 770); stubs only in TK-01 |
| Backdrop | low ground from TR-01a `TerrainSynthesis` around the SEG1 bounding box (ADR-007 impact review) |

Heights are set by the builder from these rules: layer step ≥ 7 m at crossings; grades ≤ 12 % on B, ≤ 18 % on A; convex crests only (no blind dips before turns); no hidden hazards.

## Out of scope
Opening the class connectors (CL-01), sidecar/heavy vehicles (VH-01/02), rivals (AI-03), weapons, art beyond greybox + placeholder context props (no testing on bare terrain), segments 2–4.

## Public interfaces (TK-01a)
```csharp
namespace Convoy.Race
{
    public enum LayerFallMode { LandAndContinue = 0, ResetToRoute = 1, Hybrid = 2 }

    [CreateAssetMenu(fileName = "RaceRulesConfig", menuName = "Convoy/Race Rules Config")]
    public sealed class RaceRulesConfig : ScriptableObject
    {
        public LayerFallMode layerFallMode = LayerFallMode.Hybrid;   // O-004: PT-A decides
        [Min(0f)] public float fallMinAirSeconds = 0.6f;            // shorter airtime is a bump, not a fall
        [Min(1f)] public float voidProbeMetres = 60f;               // Hybrid: no road this far below = void → reset
    }

    /// Pure: decides what a fall does. EditMode-testable.
    public static class LayerFallRules
    {
        public static bool IsFall(int lastGroundedLayer, int newGroundedLayer, float airSeconds, RaceRulesConfig c);
        public static bool ShouldReset(LayerFallMode mode, bool roadBelow);   // Land: never; Reset: always; Hybrid: !roadBelow
    }

    /// Per vehicle. Reads grounded layer from wheel hits (road colliders on Road_L0..L2), logs falls (event), triggers reset when rules say so.
    public sealed class LayerFallMonitor : MonoBehaviour { public event System.Action<int, int> Fell; /* (fromLayer, toLayer) */ }

    /// IRecoveryPointProvider with a layer index per route point; searches only the last grounded layer (ADR-007 §4).
    public sealed class TrackRecoveryPoints : MonoBehaviour, Convoy.Vehicle.IRecoveryPointProvider
    {
        public void Configure(Rigidbody body, Vector3[] points, int[] routeStarts, byte[] layers);
        public void SetLastGroundedLayer(int layer);
        public bool TryGetRecoveryPose(out Pose pose);
    }
}
```
`LayerFallMonitor` needs the wheels' current hit layer. `VehicleController` already raycasts each wheel; TK-01a adds a read-only `int GroundLayerOf(int wheel)` getter (returns `-1` when airborne). This is the only `VehicleController` change; it needs the JACKAL handling regression test (README hard rule).

## Acceptance criteria
1. **EditMode (TK-01a):** `LayerFallRules` truth table for all three modes (incl. airtime below threshold = not a fall, same-layer landing = not a fall); `TrackRecoveryPoints` with two stacked routes 8 m apart returns a point on the requested layer; 0 B GC per query after warm-up.
2. **PlayMode:** JACKAL handling regression test still passes after the `GroundLayerOf` getter.
3. **Integration:** `TK01_Segment1Setup.ApplyToScene("Assets/_Convoy/Scenes/T01_Seg1.unity")` is idempotent; SEG1 builds from `T01_topology.json` + the authored height table; all roads inside 5 km of the origin.
4. **Toggle:** switching `layerFallMode` in the asset (no code change) produces the three behaviours, checked by Gabriel at C2 (drive off the bridge edge) and on A's high ledge.
5. **Playtest checklist (TK-01c, Gabriel + one outside player):** a first-time player completes SEG1; each layer (L0/L1/L2) is used in ≥ 1 of 3 runs; both A and B are taken at least once; no wheel snag; ≥ 60 fps.
6. **Measured times:** clean JACKAL run times on A-only and B-only for M0→C3 and C3→M4a, written into `T01_topology.md`; target Δ ≤ 2 s per ~60 s (D-037). If over, the PR proposes the shortening (do not silently change the layout).
