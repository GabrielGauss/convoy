# Spec TR-01 — Páramo open terrain slice (`Paramo_01`, 2 km × 2 km)

- **Human owner/reviewer:** Gabriel (feel, layout) + Narrative & Game Designer (route tuning) · **Builder agent:** combat-engineer (a, c), orchestrator runs b/c in Unity · **Architecture:** ADR-001, ADR-004 (D-019), ADR-006 (D-023 `Convoy.Level`, D-027, D-029, D-030), D-021 (free Unity Terrain only)
- **Split:** **TR-01a** pure synthesis + `TerrainLayout` SO + `WorldVariation` selection + EditMode tests · **TR-01b** editor generator → `Paramo_01.unity` (orchestrator runs it) · **TR-01c** world-variation runtime, rival route export, route recovery

## Objective
A scaled-down D-021 Páramo: one open 2 km × 2 km Unity Terrain, start pad on the south edge, the **Monolith** (tall pillar, cyan beam) inside a volcanic crater at the centre, three player routes (east **canyon** with a **chasm jump** shortcut, centre **toxic-river ford + cave**, west **open desert** with a **minefield** and a **Rammer gate** shortcut (LV-01)), toxic mud at fords (LV-02), and three rival AI convoys arriving from W/N/E edges on their own polylines. It must feel open: **no checkpoints, no invisible walls**; the world edge is a natural berm too steep to climb, hidden in dust fog. Everything is generated from data by a re-runnable script — nobody hand-edits the scene.

## Out of scope
Race loop on this map (start/finish/uplink/medals — see Open questions), mine damage (mines are inert markers), chasm bridge terminal, spider fauna, trees/grass/detail meshes, final art, terrain holes, multiple terrain tiles, networking.

## TR-01b generator — `ApplyToScene(scenePath)`
1. Open scene (create + save if missing). Load/create layout; refuse if `layout.generatorVersion > GeneratorVersion`.
2. `TerrainSynthesis.Build` → `TerrainData` (size 2000 × 300 × 2000, `SetHeights` normalised [z, x]); `ComputeSplat` → `SetAlphamaps`. Terrain object `Paramo_Terrain` at (−1000, 0, −1000) reused if present; `TerrainCollider` shares the data.
3. Draw settings: `drawInstanced` on, `heightmapPixelError` 5, `basemapDistance` 400, shadows on, no trees/details. Scene: one directional light (create if none), fog exp² with `clearFogDensity`, `Camera.main.farClipPlane` 1500 if a camera exists.
4. Rebuild root `Paramo_Generated` (only this root's children are deleted/recreated): `Monolith` (box 8×80×8 basalt + emissive cyan beam cylinder 1×400 m, no collider on the beam), spawns (`Spawn_Player`, `Spawn_Rival_W/N/E` empty transforms on the ground), chasm ramp (box wedge), cave roof slabs (boxes over the covered range, 9 m clearance), shortcut blockers (5-box rockfall, inactive), mine slots (red emissive discs, inactive, no collider), river ribbon, rocks. `RammerGate.prefab` / `MudPatch.prefab` instanced if they exist; otherwise a named placeholder marker + `LogWarning` (re-run after LV-01c/LV-02c).
5. If present, call `F03…ApplyToScene` and `C01…ApplyToScene` (player Jackal at `Spawn_Player`, input, camera). Save scene. Idempotent: a second run yields the same object set and identical heights.

## Acceptance criteria
Fast tests use a synthetic 500 m / 257² layout (same 1.95 m spacing); `[Category("Slow")]` tests run `ParamoLayoutDefaults` at 1025².
1. **Determinism:** `Build` twice on the same data → bit-identical `Heights`; seed + 1 → ≥ 5 % of cells differ by > 0.01 m. `DeterministicRng(7)` first 3 values pinned in the test.
2. **Crater:** centre height = base − floorDepth + plateauHeight ± 0.5 m; on 32 radial rays avoiding route gaps, the max lies at rimRadius ± 2 samples and ≥ base + rimHeight − 2 m; floor slope ≤ 3° for plateauRadius + 5 < r < 0.8 × floorRadius.
3. **Drivable routes:** every route (defaults), sampled every 2 m: longitudinal slope ≤ `maxRouteSlopeDeg` + 0.5° (chasm gap excluded); cross slope ≤ 6° for |lateral| ≤ width/2 − 1 m; every Main route connects its spawn pad to the plateau.
4. **Chasm:** along the `chasm` shortcut the span with bed < lip − depth/2 is `gapWidth` ± 2 m long and ≥ depth − 1 m deep; `MinClearSpeed(24, 12, 2)` = 20.4 ± 0.1 m/s; for defaults it lies in [15, 0.8 × Jackal topSpeed 40 = 32] m/s.
5. **River & edge:** river centre bed = local bank − depth ± 0.5 m away from fords; edge band max slope ≥ 30° except within spawn `padRadius`; spawn pads ≤ 3°.
6. **Splat/sampler:** weights sum to 1 ± 1e-4 per texel; toxic layer dominant on river-bed texels; `SampleRoute` spacing = spacing ± 0.01 m (XZ), first/last = route ends, y = `Sample` ± 0.05.
7. **Variation:** same seed → identical result and active slots; over seeds 1..1000 storm rate = chance ± 0.05; open count ∈ [min, max]; exactly `activeMines` active, none within `safeLaneHalfWidth` of the chosen lane; `MineSlots` identical for the same layout seed; `Select` 0 B GC with pre-sized lists.
8. **Generator (TR-01b, orchestrator in Unity):** clean run creates scene + assets with 0 errors; second run: same object count under `Paramo_Generated`, same TerrainData GUID, heights unchanged; nothing outside the root deleted; full generation ≤ 15 s.
9. **Rival export (TR-01c):** each default rival route → `PolylinePath` length within 1 % of its sampled length; `CurvatureAt(d, 20)` ≤ 1/25 m⁻¹ everywhere; generated `RacingLine` waypoints 10–15 m apart. `RouteRecoveryMath` returns the nearest point and a unit tangent; 0 B GC.
10. **Manual (Gabriel, after TR-01c):** drive start → Monolith on each main route; chasm cleared with nitro, safe detour exists; Rammer gate breaks at ≥ 80 km/h; mud slows at fords; driving at the edge you are stopped by slope, never by an invisible wall; falling into chasm/river → V-02 reset puts you back on a route; 3 rivals reach the crater; storm runs visibly differ; ≥ 60 fps in the Editor Game view (1080p, Stats) at start pad, crater rim and desert, on Gabriel's mid PC.

## Performance budget
≥ 60 fps in Editor on a mid PC (GTX 1660 / RX 6600 class). **Heightmap 1025²** = 1.95 m spacing: resolves the smallest features (12 m roads + 10 m shoulders, 24 m chasm walls ≥ 2 samples); 513² (3.9 m) stair-steps roads; 2049² quadruples memory (2 → 8 MB + PhysX heightfield) and generation time with no visible gain at chase-camera height. One terrain tile, 4 layers = one splat control map = single pass; alphamap 512² (3.9 m) enough for slope/biome blends. `heightmapPixelError` 5, `basemapDistance` 400, instancing on; far clip 1500 m hidden by fog; ≤ 200 generated objects, primitives static-flagged; no per-frame scripts except AI/vehicles (runner/atmosphere run once).

## Risks
- Grade-limited carving can leave cliffs at route shoulders in steep canyon noise → shoulder blend + AC 3 cross-slope check; tune region amplitude in data.
- Heightmap terrain cannot overhang → cave = covered trench with roof slabs (no terrain holes); rivals avoid it.
- Per-run variation breaks ghost/medal comparability (D-022/D-026) → open question; `fixedSeed` lets timed modes pin the world.
- TerrainCollider at 1.95 m + raycast wheels: small bumps at shoulder seams; V-01 handling regression unaffected (Sandbox untouched).
- Editor-only generation (~5–15 s) is fine; never run synthesis at runtime in M1.
- Open map + no checkpoints conflicts with D-022 split times → needs a decision before a race loop lands here.
