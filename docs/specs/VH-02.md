# Spec VH-02 — Heavy (H-02 MULE)

- **Human owner/reviewer:** Gabriel (feel) · **Builder agents:** vehicle-engineer (config), combat-engineer (Rammer class flag), orchestrator (prefab) · **Architecture:** ADR-007 §2–§3 (D-035, D-038) · **Blocked by:** VH-01a (class plumbing)
- **Split:** **VH-02a** `RammerGateConfig.breakerClasses` + rule change + tests (LV-01 amend) · **VH-02b** heavy data: `Heavy_VehicleConfig`, `Heavy_DamageConfig`, `Heavy_SeatLayout` · **VH-02c** integration: `VH02_HeavySetup` builds `Heavy.prefab` (greybox), places a Heavy-only Rammer wall in `TrackKit_Test`

## Objective
The third class: slow to accelerate, hard to stop, armoured, three seats, the only class that breaks Rammer walls, partly immune to mud, the worst jumper. Same controller, different numbers (4 wheels, all driven).

## Scope
- **Level (LV-01 amend):** `[System.Flags] public enum VehicleClassMask { None = 0, Sidecar = 1, Jackal = 2, Heavy = 4, All = 7 }` in Core next to `VehicleClass`; `RammerGateConfig.breakerClasses = VehicleClassMask.Heavy`; `RammerGateRules.ShouldBreak(closingSpeed, mass, VehicleClass cls, config)` returns false when the class is not in the mask. Kept: the old overload behaves as `All` so LV-01b tests pass unchanged. `RammerGate` reads the class with `GetComponentInParent<IVehicleClassSource>()` **once per contact** (not per step), cached by `Rigidbody` instance id.
- **Data:** heavy `VehicleConfig` (mass ~2800 kg, topSpeed ~34 m/s, engineForce scaled for the slowest 0–100), `DamageConfig` (maxHealth ~180, lower damage per m/s), `SeatLayout` (Pilot, Gunner, Engineer), `ClassTraction` heavy row ≈ 0.85 mud penalty.
- **Pushing lighter vehicles:** comes from mass alone (no code). VH-02c checklist confirms it.

## Out of scope
Fragile bridge (CL-01), heavy weapons (WP-01), AI heavy (AI-03), final model.

## Acceptance criteria
1. **EditMode:** `ShouldBreak` — heavy at break speed breaks; JACKAL at break speed with enough mass does **not** break a Heavy-only wall; `All` mask = old behaviour (existing LV-01 tests green); NaN still never breaks.
2. **PlayMode:** a Heavy-only wall in `TrackKit_Test`: heavy at ≥ break speed breaks it; JACKAL at full boost bounces off (impact damage as any wall).
3. **Integration:** `VH02_HeavySetup` idempotent; `Heavy.prefab` drives in `Sandbox` and `TrackKit_Test`.
4. **Gabriel checklist:** slowest 0–100 of the three; fails the TK-00 speed-gated jump even with boost; noticeably less slowed by mud than the JACKAL; pushes the sidecar aside in contact; still fun to steer (not a barge).
5. JACKAL handling regression test unchanged.

## Allowed files
`Scripts/Core/VehicleClass.cs` (add mask), `Scripts/Level/{RammerGateConfig,RammerGateRules,RammerGate}.cs`, `Tests/EditMode/Level/RammerGate*Tests.cs`, `Tests/PlayMode/RammerGateTests.cs`, `Editor/Integration/VH02_HeavySetup.cs`; orchestrator: `Config/Vehicles/Heavy_*.asset`, `Config/Level/RammerGate_*.asset`, `Prefabs/Vehicles/Heavy.prefab`, `Scenes/Test/TrackKit_Test.unity`, metas.
