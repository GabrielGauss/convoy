# TR-01 — Páramo terrain slice (open world, M1)

- **Status:** spec-needed (architect)
- **Decision:** D-031 · **Human owner:** Gabriel (feel, layout) · **Builder:** level/tools engineer · **Integration:** orchestrator in Editor
- **Goal:** one 2 km × 2 km Unity Terrain (free) with the Monolith in a central crater, player spawn at one edge, ≥ 3 real routes (canyon, toxic river crossing, open desert/minefield), Rammer rock (LV-01), mud (LV-02), a chasm jump, uplink at the Monolith (UP-01). No checkpoints or invisible walls; soft world edge.
- **Approach:** editor generator script builds the terrain from a `TerrainLayout` ScriptableObject (heightmap noise + carved route splines + crater + river channel), so layout iterates by data, not hand-sculpting. Routes stored as polylines reused by A-01 rival AI.
- **Per-run variation (retry driver):** `WorldVariation` seed picks storm on/off (URP fog), which shortcut is open, mine layout.
- **Acceptance:** Jackal crosses spawn → Monolith on each route in 1.5–2.5 min; ≥ 60 fps in Editor on Gabriel's PC; Jackal handling unchanged (V-tests green); 0 new paid assets.
- **References:** Gabriel's maps 2026-10-11 (PÁRAMO technical map, PÁRAMO-NEXUS concept), `docs/design/PARAMO-NEXUS_vision_es.md`.
